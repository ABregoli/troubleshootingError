
# Project Workspace Instructions

## General
- Analizza l'intero progetto prima di proporre modifiche.
- Considera tutti i file sorgente, header e configurazione.
- Ricostruisci le dipendenze tra classi e moduli.
- Non inventare funzioni o classi non presenti.
- Mantieni la compatibilità con il codice esistente.

## C++ Analysis
- Analizza file .cpp, .h, .hpp, .cc e .c.
- Individua classi, strutture, namespace e funzioni.
- Ricostruisci le relazioni tra classi.
- Individua dipendenze esterne e librerie.
- Verifica possibili problemi di memoria e puntatori.
- Individua duplicazioni e codice inutilizzato.

## Visual Studio
- Analizza .sln, .vcxproj e .props.
- Considera configurazioni Debug e Release.
- Verifica piattaforme Win32 e x64.
- Non modificare le configurazioni senza autorizzazione.

## CMake
- Analizza CMakeLists.txt.
- Ricostruisci dipendenze e target.
- Verifica percorsi delle librerie.

## Safety
- Non modificare file durante le analisi.
- Non eliminare file.
- Non eseguire comandi distruttivi.
- Prima di qualsiasi modifica chiedi autorizzazione.

## Workflow
1. Esplora la struttura completa.
2. Identifica i moduli principali.
3. Analizza le dipendenze.
4. Individua eventuali problemi.
5. Produci un rapporto tecnico.
6. Attendi autorizzazione prima di modificare.
